## 🚀 Featured Projects

## 🧠 Ready to Revise — AI-Powered Intelligent Revision System

**An adaptive learning platform that personalizes revision schedules using student behavior and machine learning.**

**Tech Stack:** Kotlin • TypeScript • NestJS • Node.js • Prisma • PostgreSQL • Python • FastAPI • Scikit-learn • Docker • CI/CD

- Designed a microservices-based backend integrating behavioral signals such as student performance, confidence, response time, hesitation, and historical revision behavior.
- Built an ML pipeline for feature engineering, model training, validation, and prediction.
- Compared and tuned Logistic Regression, Random Forest, and Histogram Gradient Boosting models.
- Integrated REST APIs for question management, revision tracking, feedback collection, and automated scheduling.

**Results:** 0.84 ROC-AUC • 5+ Behavioral Signals

**A full-stack platform for managing residential society operations, resident services, and staff workflows.**

**Tech Stack:** Next.js • React • Spring Boot • MongoDB • Redis • Kafka • JUnit

- Architected a full-stack platform with a 56-endpoint REST API and MongoDB persistence.
- Implemented role-specific workflows for residents and staff.
- Built JWT authentication and four-role authorization.
- Developed complaint tracking, SLA-based overdue detection, and audit logging.
- Implemented automated API and end-to-end testing for authentication, authorization, CRUD operations, and security scenarios.
